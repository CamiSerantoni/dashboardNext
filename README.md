Dashboard Next.js

Aplicación web desarrollada con Next.js, React y TypeScript que permite visualizar información de manera dinámica mediante un dashboard interactivo. El proyecto explora buenas prácticas de arquitectura en aplicaciones frontend modernas, incluyendo gestión de estado global, componentes reutilizables y organización modular del código.

Este proyecto fue creado como parte de mi proceso de aprendizaje y práctica en el desarrollo de interfaces modernas y escalables con React y Next.js.

🛠️ Tecnologías utilizadas

- Next.js 14
- React
- TypeScript
- Redux Toolkit
- CSS / Tailwind (si usaste)
- ESLint

Estas herramientas permiten construir aplicaciones frontend escalables, mantenibles y con buen rendimiento.
