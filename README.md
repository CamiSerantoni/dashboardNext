📊 Dashboard Next.js

Aplicación web desarrollada con Next.js, React y TypeScript que permite visualizar información de forma clara mediante un dashboard interactivo.

El objetivo del proyecto es explorar buenas prácticas en el desarrollo frontend moderno, incluyendo:

Arquitectura escalable en aplicaciones React

Gestión de estado global

Componentes reutilizables

Organización modular del código

Este proyecto fue desarrollado como parte de mi proceso de aprendizaje para profundizar en la creación de interfaces modernas, mantenibles y escalables.
